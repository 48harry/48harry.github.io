# BDAI학회 (빅데이터 분석 학회, 대학생 학회) 7주차 강의 후기

# 1. 이번 주 배운것

#### 7주차 목표

- 추천시스템을 만드는 방식을 '사람없이 자동검사를 거치게' 하도록 자동화 파이프라인을 구축하는것

#### 자동 프로세스를 왜 구축해야하는가

- 상호작용 기록이 계속 쌓이고, 가장 최신 정보가 의미가 더 중요성을 가지기 때문
	- 추천 변경의 원인이 대부분 새로 들어온 정보에 의한것임

#### 자동 프로세스 (함수단위로 쪼갬)

1. 데이터 점검 (클리핑, 조건함수)
	1. 결측치처리 
	2. EDA
	3. 조건처리 (불충족하는 데이터는 버림)

2. 학습
	1. 사용자-종목표 mapping (담았으면 1, 모르면 0)
	2. 행렬분해 : 사용자요인 / 아이템요인 분할
	3. 인기순위, 이미담은종목, 번호목록 등등 저장

3. 일괄 추출 (추천)
	1. 점수 (사용자요인, 아이템요인) 높은순 정렬
	2. 위험도 상한 이하만 필터링
	3. 이미담은 종목 제외
	4. 인기순위 반영

4. 규격 검사
	1. 추천된 사항 중 문제가 있는것들을 목록에 쌓음 (Rule-base, 없으면 통과)

5. 저장
	1.  sheet 형태로 저장

#### 서비스용 모델학습

- 모델의 성능테스트가 필요없어 고객에게 추천서비스를 만들기 위해서는 train-test split 없이 전부 train에 활용함

- **학습** : 하루에 한번쯤 / 50ms (현 프로젝트기준) / 스크립트 실행
- **모델 서빙** : 앱을 열때마다 / 0.035ms (현 프로젝트기준) / API 서빙

- 빠른 제공이 목적이기에 미리 서빙내용을 정해두는것이 합리적 (개인뿐만 아니라 일괄추천도)

# 2. BDAI TrendZ 서베이 / 리포트


TrendZ 서베이는 말 그대로 'Z세대를 대상으로 진행하는 여러종류의 서베이'로 꽤나 여러 주제로 서베이가 진행되고 레포트도 많았다.

![](assets/img/Pasted%20image%2020261125181746.png)
대학생들이 데이터분석에 AI를 어떻게 활용하는가에 대해 다룬 리포트를 읽어봤는데 생각보다 흥미로운 주제들로 여러 레포트가 매달 작성되는듯 보였다.

![](assets/img/Pasted%20image%2020261125181722.png)
실제로 써먹을 수 있을정도의 표본이고, 파악하기 좋게 여러 다이어그램으로 정리되어있다

![](assets/img/Pasted%20image%2020261125182112.png)
다만 좀 의아했던건 '데이터분석시 AI를 활용하는 사람의 96%는 GPT를 쓴다'는 점
22년말 상용LLM으로 GPT3가 처음 나왔던 시절도 아니고 요즘 지난 10월에 진행된 서베이던데 이런 결과가 나온걸 보면 질문설계가 잘못된건 아닐까 하는 의심이 들긴 한다.
