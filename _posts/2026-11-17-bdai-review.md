# BDAI학회 (빅데이터 분석 학회, 대학생 학회) 8주차 강의 후기

# 1. 이번 주 배운것

### API 연결

지금까지는 단순하게 파일을 열어서 읽었다면, 이젠 API형식으로 주소를 요청하는 방법으로 구현한다. (추천 내용은 6주차와 똑같음)

- 클라이언트 : 요청을 보내는 프로그램 (앱)
- 서버 : 요청을 받아 응답하는 프로그램

### 흐름

1. 찾기 : 결과파일에서 특정 사용자의 추천만 찾음
2. 확인 : 찾은 추천이 있는지 확인 (없으면 404)
3. 고르기 : 순위가 높은것만 고름
4. 정리 : 고른것을 응답에 쓸 shape로 정리
5. 응답 : 결과 전달

### Error code

- 2xx 계열 : 성공
- 4xx계열 : 클라이언트쪽 문제
- 5xx계열 : 서버쪽 문제

### 요청주소

예시
https://localhost:7000/recommend/U001?k=3

1. localhost :  서버 (루프백주소)
2. 7000 : 포트
3. recommend : 엔드포인트
4. U001 : 경로 매개변수
5. ?k=3 : 쿼리 매개변수

### 메서드

1. GET 메서드
	1. 서버에서 정보를 가져옴
	2. /health, /recommend 등 정보를 조회만 함

2. POST 메서드
	1. 서버에 데이터를 보내 처리를 요청함
	2. 값 변경 등

### Swagger

Swagger UI를 활용해서 API health check나 GET 메서드가 정상적으로 작동하는지 확인할 수 있음



# 2. 블챌

💼 BDAI 패스트트랙이란?  
BDAI 패스트트랙은 기업의 채용 수요와 BDAI 인재풀을 연결하는 추천채용 프로그램입니다.  
데이터·AI, 개발, 기획, 마케팅, 경영지원 등 다양한 직무의 채용 기회를 제공하며, 기업별 협의에 따라 BDAI 추천채용 지원자에게 특별한 채용 혜택을 지원합니다.  
  
👑 BDAI 추천채용만의 특별한 혜택  
1. BDAI 인재풀 별도 분류  
2. 우선·신속 서류 검토 지원  
3. 기업 연결 및 빠른 답변 지원  
  
※ 구체적인 지원 방식과 혜택은 기업별로 상이하며, 최종 선발은 각 기업의 채용 기준과 절차에 따라 진행됩니다.
